# Vorrat

Einkaufs- und Vorrats-App für den Haushalt: Einkäufe erfassen, Lagerbestand nach Lagerort oder Kategorie ansehen, Artikel mit einem Tipp entfernen, ganzes Lager auf einmal leeren (mit Rückgängig).

## Stand

- `index.html`: aktuelle Version der App (eine Datei, ohne Build-Schritt). Speichert derzeit noch über den Claude-Artifact-Speicher, lokal im Browser als Rückfall.
- Geplant: Umbau auf Supabase (Login mit E-Mail und Passwort, gemeinsamer Bestand im Haushalt), installierbar auf Android, Hosting über GitHub Pages.

## Umfang Version 1

Artikel erfassen (Name, Menge, Einheit, Lagerort, Kategorie, optional Haltbarkeitsdatum, Preis, Geschäft), gruppierte Lageransicht mit Suche, Entfernen mit einem Tipp, Gruppe leeren, Lager leeren, Rückgängig.
